Рентген проекта

Мини-сайт для анализа ZIP-архива: считает число файлов, суммарный несжатый размер
и показывает таблицу с путями, расширениями и размерами. Анализ выполняется целиком
в браузере. Сервер не требуется.

Установка

- Требуются Node 18+ и npm
- В каталоге project/:
  - npm install

Скрипты

- npm run dev — запустить сайт (Vite)
- npm run check — проверка типов, тестов и сборки

Лимиты (по умолчанию)

- размер загруженного ZIP: 20 МиБ
- число записей архива (включая папки): 2000
- суммарный несжатый размер файлов: 100 МиБ

Проверка

- Из корня практики: node .opencode/scripts/check.mjs
- Через интерфейс: загрузите .zip, нажмите «Проанализировать»,
  проверьте сводку и таблицу. Ошибки отображаются в панели.
