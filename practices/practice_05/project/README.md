# Рентген проекта

Мини-сайт для анализа ZIP-архива: считает число файлов, суммарный несжатый
размер и показывает таблицу с путями, расширениями и размерами. Дополнительно
строит граф зависимостей C#-проекта: проекты, исходные файлы, пакеты и связи
между ними. Анализ выполняется целиком в браузере, сервер и сеть не нужны.

## Возможности

- Загрузка локального ZIP и понятные ошибки для пустого, повреждённого или
  неподходящего архива.
- Сводка: имя архива, число файлов, суммарный несжатый размер.
- Таблица файлов: путь, расширение, размер; сортировка по пути.
- Вкладка «Граф»:
  - `ProjectReference`, `PackageReference` и `using` между `.cs`-файлами;
  - детали выбранного узла, связи и неразрешённые ссылки;
  - переход к строке таблицы для проекта или исходного файла;
  - подсветка входящих и исходящих связей выбранного узла;
  - список и интерактивный граф, упрощение больших графов;
  - клавиатурная навигация: `Tab`, `Enter`/`Space`, `Esc`.
- Неразрешённые ссылки показаны отдельным списком с фильтром, без фиктивных
  узлов и рёбер.

## Установка и запуск

Требуются Node.js 18+ и npm.

```bash
cd project
npm install
npm run dev
```

Vite выведет адрес вида `http://localhost:5173`.

## Скрипты

- `npm run dev` — запустить сайт в режиме разработки.
- `npm run typecheck` — проверить TypeScript.
- `npm run test` — запустить тесты Vitest.
- `npm run build` — собрать production-версию.
- `npm run check` — typecheck, тесты и сборка одной командой.

## Что анализирует граф

- Только файлы `.cs` и `.csproj`; остальные типы, `.sln`, `obj/` и `bin/`
  не читаются.
- C#-код не выполняется и не компилируется. `using` и namespace определяются
  эвристически по тексту, поэтому возможны честно показанные неразрешённые
  ссылки.
- Содержимое файлов не попадает в результат графа: только пути, имена,
  версии, условия и предупреждения.
- `.env`, ключи и другие секреты не читаются.

## Лимиты

Архив:

- размер ZIP — не больше 20 МиБ;
- число записей, включая папки, — не больше 2000;
- суммарный несжатый размер — не больше 100 МиБ.

Граф:

- отдельный `.cs`/`.csproj` больше 1 МиБ не читается: узел получает статус
  «неизвестен», а граф — предупреждение;
- суммарный текст для разбора — не больше 20 МиБ;
- узлов — не больше 3000, связей — не больше 10 000.

Отображение:

- до 200 узлов и 500 связей граф показывается полностью;
- до 1000 узлов и 3000 связей доступен упрощённый интерактивный граф;
- выше этих порогов остаётся полный список.
