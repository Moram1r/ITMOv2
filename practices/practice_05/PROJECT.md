# Рентген проекта

Учебный сайт, который помогает быстро разобраться в содержимом репозитория,
загруженного ZIP-архивом. Внутри приложения не нужна нейросеть.

Первый работающий вариант:

1. Пользователь выбирает ZIP и запускает анализ.
2. Сайт показывает количество файлов, суммарный размер их содержимого и таблицу:
   путь, расширение, размер файла.
3. Для пустого, повреждённого или неподходящего архива сайт выдаёт понятное сообщение.

Для первой версии достаточно анализировать архив в браузере, если выбранный стек
это позволяет. Сервер добавляется только при реальной необходимости.
Конкретные ограничения размера архива, количества файлов и распакованного объёма
нужно определить до реализации; не распаковывать архив без ограничений.

Визуальное направление: полезный, выразительный инструмент исследования кода.
Красота должна помогать читать результаты. Для первой версии достаточно загрузки,
сводки и таблицы. Более сложные визуализации обсуждаются отдельными задачами.

Базовый вариант реализован в `project/` и принят как исходная версия.
Подключён Spec Kit для дальнейшей работы. Новые функции описываются
и реализуются отдельными задачами.
